# Connect the lovable-edu-suite tools

## Your step (in the Lovable desktop app)
1. Open Settings, then Connectors, then Local MCP servers.
2. Add a new server that points at `~/Tools/mcp-servers/lovable-edu-suite`. Use the start command from that folder's README, for example `node index.js` or `npx .`.
3. Turn it on for this project, then send me a message in this chat.

## My steps after it's connected
1. List every tool the suite offers and tell you what each one does in plain words.
2. Suggest which ones fit Hero Board, like schedule, roster or lesson tools.
3. Use or wire in only the tools you pick. Nothing on the board changes until you choose.

## Notes
- I can only reach those tools while the desktop app is open on your computer.
- If the server won't start, paste its error or upload the folder as a zip instead.
