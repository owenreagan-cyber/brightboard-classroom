# Brightboard Classroom

i am looking to make a website-like presentation board that will be used to display messages to my first grade classroom. Using high quality designs - like Canvas and other imaging - to create boarders, graphics, icons, ui, ect, i want it to be like "classroomscreens.com" and a "google slides" presentation so that i can have a slide for "morning messages" letting students know what their morning work is, creating toolts and widgets, embedded items like: a timer, random name selector, "work symbols" auto run timers in a sequences - i set a time: 7:40 and every minutes later the next timer starts with a description (classroomscreen.com feature).

Then i can have a math welcome page on the next slide, lunch rules, ect.

I would really like an injector or a very easy way to update the pages. Connect spotify or embed to have a school catered playlist. Enable Lovable Cloud so slides, schedules, and rosters persist across devices.
